# V5 06 local coaching and Indic report acceptance

October 29, 2026. Local software and rendered-page verification only. Hindi and Telugu remain acceptance previews. Fluent-speaker approval is not complete. The user volunteered to review Telugu; that is not approval. Hindi has no assigned human reviewer.

## Changes

- Added a versioned `insurance-rubric-v5` / `localized-quality-v2` evaluator. Coordinated Telugu exclusion lists retain their sentence context. A cosmetic-treatment mention alone no longer invents affirmative coverage. Telugu acknowledgement variants and review-before-decision wording are recognized.
- Frozen v4 scoring and evidence validation remain in `v4-rubric.ts`. Refreshing an existing native report creates a separate v5 row, retaining v4 and the original transcript, source metadata, events, state and snapshots. English v1/v2/v3 scoring is unchanged.
- Added bounded checks for statements denying the exercise's supplied fixed facts. Genuine earlier contradictions remain in the full-history score; later corrected evidence is listed separately. This remains a phrase matcher, not general semantic or factual verification. Quoted statements, complex negation and unrecognized paraphrases can still require review.
- Native report-card companions, downloadable feedback and email/WhatsApp summaries have Hindi/Telugu wording with an explicit draft-review notice. Canonical feedback and coaching metadata remain English; the native text is a presentation translation, not a silently changed coaching preference. Cross-language score equivalence has not been established.
- Indic PDF uses server-side Chromium shaping and locally bundled Noto fonts, with tagged PDF, A4 pagination and original-script evidence. No report markup is interpreted as user HTML; all fields are escaped, network requests blocked and JavaScript disabled. Rendering is bounded to one concurrent Indic job per process, with browser cleanup and a deadline. Missing Chromium produces an actionable error while Word remains available.
- Native Word embeds Noto Sans, Noto Sans Devanagari and Noto Sans Telugu, selects fonts per script run and sets complex-script properties. Mixed Hindi/Telugu/Latin originals remain Unicode. Indic text in an English export also routes through the shaping renderer.
- Local preview exports retain ownership, origin, current revision and private/no-store safeguards. Public production activation remains closed pending language acceptance.

## Verification

See `verification/v5-06/acceptance.json` for final counts. Automated tests include the reported false-positive exclusion and missed acknowledgement cases, original v4 validation, invented reference rejection, correction references, native downloads, private sharing summaries and ownership/origin/stale-report rejection.

Synthetic sample exports are generated by `npm run verify:reports:indic` under ignored `output/reports/v5-06/`. They contain public fictional samples, not a user's private transcript. Six equivalent sample answers produce all nine checks in both languages; this is a finite regression fixture, not proof of general score equivalence.

The PDF pages are rendered with bundled Poppler; the Word files are rendered with bundled LibreOffice and the document skill renderer. Every resulting page is visually inspected for glyph placement, conjuncts/matras, rupee symbols, wrapping, clipping and pagination. Embedded Word font parts and PDF Unicode/rupee extraction are checked separately. Successful LibreOffice rendering does not prove identical layout in Microsoft Word, Google Docs or every phone reader.

## Server runtime

`playwright-core` is a production dependency, but a Chromium executable must be provisioned on the server. On this Mac, the renderer uses installed Google Chrome. On Linux/AWS, install a compatible Chromium runtime and set `PERSONA_PDF_BROWSER_PATH` to its absolute executable path. Run Chromium under a dedicated unprivileged service user with its sandbox available. No `--no-sandbox` workaround is used. Browser provisioning and AWS execution remain deployment acceptance work.
