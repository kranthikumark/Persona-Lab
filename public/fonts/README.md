# Bundled Indic UI fonts

Unmodified Noto Sans Devanagari and Noto Sans Telugu variable TTFs, downloaded October 29, 2026 from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
- https://github.com/google/fonts/tree/main/ofl/notosanstelugu

Each font's SIL Open Font License is included beside it. Fonts are served locally, with no runtime font-CDN dependency. These assets are for browser shaping; PDF/DOCX Indic shaping and pagination are separate V5-06 acceptance work.
